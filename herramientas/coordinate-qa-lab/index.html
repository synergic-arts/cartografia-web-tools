05 · SALIDA

Exporta el control

El CSV auditado conserva tus campos y añade qa_status, qa_reason, qa_lon y qa_lat. Los datos no salen de este navegador; solo el mapa base y la búsqueda opcional usan servicios externos.

Privacidad y trazabilidad. El archivo se procesa en memoria local. No se guarda ni se envía a un backend propio. Mapa: OpenStreetMap; búsqueda opcional: Nominatim.
