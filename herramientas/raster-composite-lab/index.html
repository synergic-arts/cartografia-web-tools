Crea una composición para revisar estadísticas.

Una imagen PNG/JPEG/WebP no contiene por sí sola un CRS fiable. Esta composición es una vista radiométrica exploratoria; para análisis científico utiliza bandas georreferenciadas, metadatos y una cadena de calibración documentada.

Procesamiento local por diseño. Las bandas no se suben a un backend y las exportaciones se generan en el navegador.
