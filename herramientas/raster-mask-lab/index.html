64 · TELEDETECCIÓN · CLIENTE · LOCAL

Separa una señal y mira dónde aparece.

Genera una máscara exploratoria desde una imagen local usando brillo, dominancia RGB, saturación o distancia a un color de referencia. Es útil para cribados rápidos de ortofotos e imágenes renderizadas antes de pasar a un flujo ráster completo.

1

Imagen y criterio

La imagen nunca sale del navegador.

En modo «Distancia», haz clic en la imagen original para elegir el color objetivo y usa la tolerancia. En los demás modos se acepta el rango entre los dos límites.

Color objetivo: RGB 80, 150, 110

La imagen sintética de ejemplo está lista para procesarse localmente.

Crea una máscara para revisar sus parámetros.

Una imagen PNG/JPEG/WebP no contiene por sí sola un CRS fiable. Esta máscara es una clasificación visual exploratoria; para análisis cuantitativo utiliza un ráster georreferenciado y conserva su metadato espacial.

Procesamiento local por diseño. La imagen y los píxeles no se envían a un backend. Las exportaciones se generan en el navegador.
