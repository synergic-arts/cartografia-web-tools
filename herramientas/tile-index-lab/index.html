Método y privacidad

Un índice reproducible para flujos web

La herramienta usa la convención XYZ de Web Mercator: X aumenta hacia el este y Y desde el norte hacia el sur. El índice incluye los límites de cada tesela, zoom, X, Y y la URL construida con tu plantilla. No descarga imágenes ni inicia peticiones a la plantilla.

Los archivos se leen y procesan en este navegador. No se envían a un servidor propio. La vista usa teselas de OpenStreetMap; consulta sus condiciones de uso.
