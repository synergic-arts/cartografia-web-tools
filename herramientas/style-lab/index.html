SALIDA REPRODUCIBLE

Leyenda

La capa exportada conserva los atributos originales y añade campos _style_.
ColorClaseEntidades
Carga una capa para comenzar.

Qué exporta: el GeoJSON incorpora `_style_field`, `_style_class` y `_style_color`; la especificación JSON conserva método, paleta, opacidad, radio y una expresión de pintura compatible como punto de partida para MapLibre.

Privacidad: el archivo se procesa localmente. El mapa base solicita teselas directamente a OpenStreetMap y muestra su atribución; puedes seguir usando la clasificación y las exportaciones aunque no haya conexión.
