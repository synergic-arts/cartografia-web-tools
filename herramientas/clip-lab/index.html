63 · RECORTE VECTORIAL · CLIENTE · LOCAL

Trabaja solo con el área que necesitas.

Recorta puntos, líneas y polígonos GeoJSON por una caja WGS84. El proceso genera geometrías nuevas, conserva los atributos y deja claro qué entidades quedaron fuera o fueron modificadas.

1

Capa y área de interés

El recorte se ejecuta completamente en el navegador.

La caja usa longitud/latitud WGS84 en grados decimales. Las líneas se dividen si entran y salen varias veces; los polígonos se recortan por anillo.

El ejemplo está listo para recortarse en local.

Recorta una capa para revisar sus entidades.

El recorte utiliza geometría planar sobre grados WGS84 para las intersecciones. Para análisis de precisión, reproyecta después la capa a un CRS métrico adecuado y valida topología.

Procesamiento local por diseño. El GeoJSON no se envía a un backend. Leaflet y el mapa base solicitan teselas directamente a OpenStreetMap. Atribución de OpenStreetMap.
