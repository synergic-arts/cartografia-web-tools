61 · VISIBILIDAD · CLIENTE · LOCAL

Descubre lo que alcanza la mirada.

Calcula una cuenca visual exploratoria desde una malla local de elevaciones. El análisis compara ángulos de terreno entre celdas, permite cambiar el observador con un clic y exporta cada celda con su estado de visibilidad.

1

Modelo y observador

CSV, JSON o GeoJSON de puntos con elevación.

La ubicación se ajusta a la celda de elevación más cercana. Haz clic en el mapa para mover el observador; deja la distancia a 0 para analizar toda la malla.

La malla de ejemplo está lista para analizarse en local.

2

Cuenca visual

Calcula una cuenca visual para revisar las celdas.

El método no sustituye un análisis SIG con un MDT validado: depende de la resolución, el sistema de coordenadas, la vegetación, los edificios y la altura del observador. Los datos permanecen en el navegador.

Procesamiento local por diseño. El GeoJSON y la malla no se envían a un backend. Leaflet y el mapa base solicitan teselas directamente a OpenStreetMap. Atribución de OpenStreetMap.
