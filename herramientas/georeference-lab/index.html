03 · CONTROL ESPACIAL

Puntos de control en el destino

—
Se muestra si las coordenadas parecen lon/lat WGS84.

El mapa se activa cuando los destinos están dentro de lon −180…180 y lat −90…90. Para UTM u otros CRS se muestra el ajuste y la tabla, pero no se fuerza una posición geográfica falsa.

05 · SALIDA

Exporta el ajuste

El world file usa la convención de centro del píxel superior izquierdo: A,D,B,E,C,F. Documenta siempre el CRS destino junto al archivo.

Privacidad y trazabilidad. Los puntos y cálculos se procesan en este navegador. No se suben imágenes ni CSV a un backend propio. Mapa: OpenStreetMap; búsqueda opcional: Nominatim.
